One line, any topic: a smart fridge serving divorce papers. The setup sounds like a gadget complaint — the punchline is a relationship one.

> My smart fridge filed for divorce — it says I only open it at 2 a.m. and never commit to anything.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (98 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
